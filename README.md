# pdobson1.github.io

Redirects only. Toast Simulator and Assault on Precinct 6-7 moved to the
[Second Reading Games](https://github.com/second-reading) organisation; links shared to their old
addresses (`pdobson1.github.io/toast-simulator/` and so on) land here and are sent on to the new
ones, deeper paths included (`404.html`).

To redirect another moved game: add its name to `MOVED` in `404.html`, and a folder with an
`index.html` like the others.
